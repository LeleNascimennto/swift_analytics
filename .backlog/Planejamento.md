# Planejamento do Projeto Swift
Cronograma e Estratégia de Desenvolvimento

Este documento apresenta o planejamento estratégico para o desenvolvimento do Projeto Swift, incluindo etapas
de limpeza de dados, análise exploratória, NLP, dashboard e apresentação final.

---

## FASE 1 — Organização e Entendimento (21/05 - 22/05)
* Entender todas as colunas da base
* Verificar dados nulos e duplicados
* Criar dicionário de dados
* Planejar o dashboard

## FASE 2 — Limpeza e Engenharia de Dados (23/05 - 25/05)
* Converter datas
* Padronizar textos
* Criar métricas de NPS
* Preparar base para NLP

## FASE 3 — Análise Exploratória (26/05 - 28/05)
* Comparar gerentes REGULAR vs TOCADORA
* Criar gráficos
* Encontrar padrões
* Detectar outliers

## FASE 4 — NLP e IA (29/05 - 01/06)
* Análise de sentimento
* Clusterização textual
* Categorias automáticas
* Insights

## FASE 5 — Dashboard (02/06 - 05/06)
* Construir dashboard
* Criar páginas analíticas
* Adicionar KPIs
* Aplicar filtros

## FASE 6 — Refinamento (06/06 - 07/06)
* Corrigir erros
* Melhorar visual
* Validar resultados

## FASE 7 — Apresentação (08/06)
* Criar roteiro
* Treinar apresentação
* Organizar storytelling

## Tecnologias Recomendadas
| Área         | Tecnologia           |
|--------------|----------------------|
| Dados        | Python + Pandas      |
| NLP          | NLTK / Transformers  |
| Dashboard    | Power BI / Streamlit |
| Visualização | Plotly / Matplotlib  |

O projeto busca transformar os dados de NPS em insights estratégicos para análise da satisfação dos clientes da
Swift.
