# swift_analytics

Projeto feito para a Swift.

## Variáveis de ambiente

As seguintes variáveis de ambiente devem ser configuradas antes de executar o projeto:

- **EXCEL_CAMINHO_TRANSACOES**: caminho do arquivo Excel com os dados de transações por loja.
- **EXCEL_CAMINHO_DADOS**: caminho do arquivo Excel com os dados gerais utilizados na análise.
